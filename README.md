# Zen Mute Toggle

Extension untuk [Zen Browser](https://zen-browser.app) (Firefox) yang mute / unmute semua tab pinned (Essential) dengan satu tombol.

- Klik sekali: semua tab Essential di-mute.
- Klik lagi (saat semua sudah mute): semua di-unmute.

## Install (temporary)

1. Buka `about:debugging#/runtime/this-firefox`.
2. **Load Temporary Add-on…** → pilih `manifest.json`.
3. Buka panel Extensions, klik kanan ikon speaker → **Pin to Toolbar**, lalu atur posisinya lewat **Customize Toolbar…**.
